# صفحه‌های جداشدهٔ چرم بهبد

این ۱۴ صفحه از خروجی HTML پروژه جدا شده‌اند. فایل index.html در ریشهٔ پروژه فهرست لینک‌هاست؛ صفحهٔ اصلی فروشگاه در pages/03-home.html قرار دارد.

| # | فایل | صفحه |
|---:|---|---|
| 1 | 01-order-success.html | نتیجهٔ سفارش |
| 2 | 02-cart.html | سبد خرید |
| 3 | 03-home.html | صفحهٔ اصلی |
| 4 | 04-account-dashboard.html | پیشخوان حساب کاربری |
| 5 | 05-shipping-details.html | مشخصات ارسال |
| 6 | 06-cart-variant.html | نسخهٔ دوم سبد خرید |
| 7 | 07-leather-authenticity-guide.html | مقالهٔ تشخیص چرم طبیعی |
| 8 | 08-karen-messenger-bag.html | محصول کیف کارن |
| 9 | 09-login.html | ورود و عضویت |
| 10 | 10-bags-collection.html | مجموعهٔ کیف‌ها |
| 11 | 11-home-variant.html | نسخهٔ دوم صفحهٔ اصلی |
| 12 | 12-karen-messenger-bag-variant.html | نسخهٔ دوم محصول کیف کارن |

## فایل‌های مشترک

- `shared.css` فونت محلی Yekan Bakh و ظاهر ناوبر ثابت را بارگذاری می‌کند.
- `shared.js` فهرست صفحه‌ها را می‌سازد و صفحهٔ فعال را مشخص می‌کند.
- `assets/fonts/` وزن‌های لازم فونت را از پوشهٔ فونت شما نگه می‌دارد تا پروژه به مسیر Documents وابسته نباشد.
